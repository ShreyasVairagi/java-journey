About This Repository

This repository documents my journey of returning to software development after completing my BSc Computer Science at Nottingham Trent University.

After graduating, I moved into warehouse operations and spent the following couple of years working outside of the software industry. During that time, I became increasingly interested in returning to technology and rebuilding the programming skills I developed during university.

I am now working through Java from the fundamentals again, building projects along the way rather than relying solely on tutorials.

The goal is to move from revising programming fundamentals to developing the skills required for a professional software development role.
